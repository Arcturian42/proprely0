# Liste outreach — 50 cibles backlinks Proprely

**Objectif** : passer de DR 0 → DR 15 en 90 jours via 30-50 backlinks qualifiés

## Légende statut backlink
- **Direct** : inscription gratuite, backlink automatique
- **Demande** : nécessite un email/formulaire de contact
- **Pitch** : nécessite un pitch éditorial (guest post, interview, étude de cas)

## TRACKING

À tenir dans une Google Sheet avec colonnes :
- Cible
- Statut (À contacter / Contacté / En attente / Accepté / Refusé)
- Date dernier contact
- URL backlink obtenu
- DR / DA estimés (via Ahrefs ou Moz)
- Notes / relances

**Cadence recommandée** :
- Semaine 1-2 : Tier 1 (15 inscriptions directes) — 100% atteignable
- Semaine 3-4 : Tier 4 (Product Hunt + BetaList) — boost massif
- Semaine 5-8 : Tier 2 (sectoriels) + Tier 6 (podcasts) — relations longues
- Semaine 6-12 : Tier 3 (presse) — itératif, multiples pitch
- Semaine 4+ : Tier 5 (partenariats produit) — discussions plus longues
